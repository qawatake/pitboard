# FEAT5 の結果

vet / test / build は通った。1 と 2 は pty 越しに確かめた (スクラッチパッド、幅 60・高さ 30)。実物の `herdr agent prompt` / `herdr pane send-*` は実行していない。

## 項目ごと

1. 送るまで届かない: `s` / `ctrl+s` で `{"op":"send"}` を追記してから AI を起こす。`changes` と hook は最新の `send` より前だけを届け、`seen` をその `send` まで進める。右上は `送信済み N` (薄く) と `● 未送信 N` (黄)。思いつきの状態は 未送信 → 未読 → 受け取った → 済
2. 送り先: `PITBOARD_SEND` が無ければ、`herdr` が PATH にあるだけで `herdr agent list` から探す (`HERDR_ENV` は見ない)。起こせなくても `send` は残し、「送る印は付けました。…」と理由・直し方を 2 行で出す
3. 開いた中身はふつうの色。`note` は `理由: …`、行の下の思いつきの行き先は `行き先: …` (頭の語だけ薄く)。済んだ項目の中身は薄いまま
4. IME が入ったまま: エディタの外では全角の英数・記号と全角空白を半角に直してキーにする。`ctrl+n` `ctrl+p` を `↓` `↑` と同じにし、`pgup` `pgdn` は半画面。案内と `?` の一覧は `j k ↑↓`
5. `-h` の作法に「問いと答え」と「チャットにしか無いものを残さない」を足した。「人の操作の受け取り方」を、まとめて送る形に書き直した (skill にも 2 行)

## 推測で決めた点

- pty での確認は、herdr の代役 (実行ファイル) を置く操作が以前拒まれたため、「herdr も PITBOARD_SEND も無い」(PATH を `/usr/bin:/bin` に) と「PITBOARD_SEND が失敗する」の 2 つで見た。「herdr にこのセッションの agent がいない」は単体テスト (代役) で確かめた
- 起こせなかったときの知らせは、1 行目に「送る印は付けました。…」、2 行目に理由と直し方を置き、それぞれ入らなければ `…` で切る (幅 60 でも理由の頭が見えるように)
- テストでは本物の herdr を呼ばないよう、送り先の無いテストは PATH を `/usr/bin:/bin` にした
- 右上は、未読と未送信が両方あれば `送信済み 2  ● 未送信 1` と並べる
- 送ったあと読まれる前に取り消した思いつきは、AI が読むときには思いつきも取り消しも出ない (AI は知らないまま)。ただし打ち込む文の N は、送った時点の件数 (取り消しを 1 件と数える)
- 一覧で開いた思いつきの状態の文は「まだ送っていません (s で送る)」「送りました。AI はまだ読んでいません」「AI は受け取りました。行き先はまだです」
- 思いつきの欄の見出しの `s で送る` は、未送信があるとき (思いつきに限らず、反応や隠すだけでも) 出す
- 行の下の思いつきに行き先があれば、その下に `行き先: …` の行を足した (これまでは状態の語だけだった)
- `ctrl+←` `ctrl+→` は FEAT4 で語単位にしたまま。`ctrl+n` `ctrl+p` はエディタの中では行の上下 (FEAT4 のとおり)
- 報告の `pgdn` は、報告の終わりが見えているときは何もしない (欄には入らない)。欄の中では `pgup` `pgdn` は何もしない
- `-h` の送る節の名前を "Send" にした (知らせの文の `pitboard -h の "Send"` と合わせるため)
