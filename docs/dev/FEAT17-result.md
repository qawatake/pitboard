# FEAT17 結果

## 直した項目

- エディタの置き場所: 書いている間は `drawEditing` で描く。エディタと案内の行をひとかたまり (上下に空行) にして、報告 (か一覧・欄) の行の間へ差し込む。画面のいちばん下の行は空け、下のコメントの欄は出さない
- `c`: 対象の行 (開いていれば中身の下。`view.ends` で行の終わりを覚える) のすぐ下。見出しは出さず、対象の行がかたまりと一緒に画面に入らないほど高いときだけ出す。字下げは対象の行の題に揃え、エディタの幅もその分狭める (`editWidth`)
- `m`: カーソルの行のすぐ下。見出しは `宛先なしのコメント` (一覧・欄からの `m` も同じ見出し)
- `e`: 一覧ではそのコメントの行 (開いていれば中身) のすぐ下。欄からは、報告の下に欄の全件を並べ、その中のコメントの位置に出す
- 位置: かたまりが画面の上から 2/3 より下に来るときはスクロールして収める。対象の行は入るかぎり見えたまま。入力が伸びても下へはみ出さない (エディタの文は今までどおり画面の 1/3 まで)
- 閉じたら元どおり: 書いている間の位置合わせは別の変数でして、報告・一覧のスクロール位置とカーソルを動かさない
- 端末のカーソル (IME) は入力位置に置く。「この行は書き換わりました」は見出しの行 (見出しを出さないときはその行だけ) に出す
- `Notice` は書いている間も画面の上に固定
- テスト: `feat17_test.go` (高さ 24・50 で上・中・下の行に `c`、5 行の入力、2/3 より上、最下行が空、閉じたあとのスクロールとカーソル、`m` の見出し、高い行での見出し、一覧と欄での `e`)。`TestEditorCursor` は空行の探し方だけ直した
- SPEC.md に「エディタの置き場所」を足し、古い記述 (画面の下に出る、欄が伸びても行が見えるように) を直した

## 推測で決めた点

- 欄からの `e` は「欄の中のその位置」を、報告の下に欄の全件を並べてその中に出す形にした (欄は書いている間は出さないため)
- `m` でカーソルの行が無いとき (止まる行が無い報告) は、画面の中ほどに出す
- エディタの中の知らせ (FIX7 の 2) は字下げせず、かたまりの中で左端から出す
- 見出しを出す「対象の行が高すぎる」は、対象の 1 行目がかたまりと一緒に画面の 2/3 に入らないとき、とした
