# FIX8: 緑の ● を消すのは `r` (読んだ) だけにする

`docs/dev/FEAT15.md` の 1 の「『見た』になるのは」の箇条は、実装が始まる前に書き換わっていたが、古い文面 (カーソルが離れたら消える) で実装されている。**いまの `docs/dev/FEAT15.md` の 1 を読み直して、そのとおりに合わせる。** この依頼はそれだけ。

要点 (正は FEAT15.md):

- 緑の ● は、カーソルを当てる・離す・開くだけでは消えない
- `r` で、カーソルの行の緑の ● を消す。案内の行には緑の印のある行にいるときだけ `r 読んだ`。`?` の一覧にも
- `y` / `n`・答え・コメントを置く・`x` で隠す、でもその行の印は消える。`A` は全部
- `r` も `u` で取り消せる
- `r` は `Option` の `key` に使えない (`check`、`-h`、仕様書)
- カーソルが離れたら「見た」にする処理と、その取り消し (`u`) の対象からの除外など、要らなくなったものは消す
