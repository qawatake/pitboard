# FEAT15 結果

## 直した項目

- 1. 自動の新着をやめ、`look="y"` (`Item` `Link` `Fold`。`Ask` と `ask="y"` に付いてもエラーにせず黄を優先) の行だけ緑の ●。値が `y` 以外は check のエラー
- 1. 「見た」は、カーソルが乗っていた行 (画面に出ていた) から離れたとき (コメントの欄・一覧へ移ったときも)。開く・反応・`c`・隠す・`A` でも。0.4 秒の滞在 (dwell) はやめた
- 1. 書き換えたら (look が付いている間) 再び未読。`Fold` は題と中身すべてで判定
- 1. 右上 `未読 N`、`space` の飛び先、`?` の説明、「反応待ちも未読もありません」。viewed ファイルに `-<hash>` 行 (取り消し) を追加。古い形式のファイルはそのまま読める
- 1. `-h`: 属性の表 (Item / Ask / Link / Fold)、Marks の説明、作法 (読んでほしい行にだけ look。進み具合には付けない。答えには付ける)、勧める構成の例 (Answers に look="y")
- 2. 左のガターを 4 桁に: 0 桁目がカーソル `>`、2 桁目が ●、その右に行頭の記号。カーソルの行でも印が出て動かない。全行で記号の列が揃う
- 2. `term.draw` を差分描画に: 前のフレームと違う行だけ `CSI r;1H CSI 2K` で書く (最初とリサイズ・外のエディタから戻った後は全部)。j/k で書き直すのは 2 行 + 案内 (+ 数が変われば右上)
- 3. `u`: この viewer で行った y/n・答え・コメントを置く/直す/取り消す・隠す/戻す・A を新しい順に取り消す。`{"op":"undo","undo":N}` を追記 (A は viewed に `-hash`)。報告・欄・一覧で効く。エディタの中では文字
- 3. 未送信なら無かったことに (前の反応に戻る、AI にも届かない)。送信済みなら新しい未送信入力: 行の右端 `取消 未送信`、`changes` は `retract y hook (題)` / `retract answer …` / `retract hide: 題` / コメントは `retract thought N` / 直しは元の文の `edit thought N` / x の取り消しは `unretract thought N`。送ったが未読のものを取り消して送ったら両方届けない
- 3. 知らせ `y を取り消しました: 題` など。無ければ `取り消せる操作がありません`。カーソルは動かさない (消えた行・コメントの上にいたときだけ次へ)。案内に `u 取り消す`、狭いと最初に落とす。`-h` に retract の読み方
- 単体テスト `feat15_test.go` と既存テストの更新 (ガター幅・dwell→離れたとき・u の挙動)。pty (幅 80) で列、離れたときに消える・書き換えで戻る、u (反応 送る前/後、隠す、A、コメント) を確認
- SPEC.md (操作の記録、反応待ちと未読、u で取り消す、コメントを取り消す)、SPEC-format.md、README、SKILL.md に反映

## 推測で決めた点

- 列の幅: `>` と `●` の間、`●` と記号の間に 1 桁ずつ空けた (計 4 桁)。その分、文の幅は 2 桁狭い (幅 80 で 74 → 72)
- 「今の u と同じ落とす順」: 今の案内に u は無かったので、`x` より先に落とす (最も低い順位) にした。行のキーが多い幅 80 では大抵落ちる (コメントの一覧などで見える)
- 置かれただけのカーソル (開いたときの最初の行) も、離れれば見たことにする
- 見たことの記録は look の無い行にも残す (A の取り消しで戻すため、と、すでに見た内容に後から look が付いても緑にしないため)
- 送信済みのものを取り消した場合だけ `取消 未送信` (反応と隠す/戻す)。コメントの直し・取り消しの取り消しは、コメントの状態が `未送信` になる
- 既存の `unretract` (直後の u) は記録の形として読めるまま残し、viewer は書かない
- 案内の「s 送る」のための未送信数には、送信済みを取り消した undo も入る
