# FEAT15: 緑の ● は AI が付けた行だけに、印とカーソルの列を分ける、`u` で直前の操作を取り消す

仕様は `docs/spec/SPEC.md` と `pitboard -h`。この依頼だけで完結する。先に `docs/dev/FEAT6.md` の印の節だけ読むとよい (いまの挙動)。

## 1. 緑の ● は「AI が見てほしいと印を付けた行」だけ

ユーザーの言葉: 「新しいものは全部緑にするのではなくAIにここを見てほしいというところをマークしてほしいかも。例えば、進行中のチェックのところとかは確認しなくて良い認識なので」

いまは「まだカーソルを当てていない行」と「当てたあとで書き換わった行」の全部に緑の ● が付く。報告を書き換えるたびに、見なくてよい行まで緑になる。

- 自動の新着の印をやめる
- `Item` `Link` `Fold` に属性 `look="y"` を足す (値は `y` だけ。`Ask` と `ask="y"` の行は黄の ● が付くので `look` は要らない。付いていたら `check` のエラーにはせず、黄を優先)
- 緑の ● は、`look="y"` が付いていて、人がその行の**いまの内容**をまだ見ていない間だけ出す。見たあとで AI が内容を書き換えたら、また出る (`look` が付いている間)
- 「見た」になるのは、人がキーで示したときだけ (ユーザーの言葉: 「緑のアイコンが消える条件が不明。ちゃんと何かキーを押して登録したい気持ち。もちろんコメントとかyとかnをつけたならそれは勝手に解消してくれるとうれしい」):
  - `r` (読んだ): カーソルの行の緑の ● を消す。緑の印が無い行では何もしない。案内の行には、緑の印のある行にカーソルがあるときだけ `r 読んだ` を出す。`?` の一覧にも足す
  - `y` / `n`、選択肢の答え、コメントを置く、行を隠す (`x`): その行の緑の印も消える
  - `A`: 全部を読んだことにする
  - **カーソルを当てる・離す・開く (enter) だけでは消えない**
  - `r` も `u` で取り消せる (3 の対象に足す)
  - `r` は viewer のキーになるので、`Option` の `key` に使えないキーに足す (`check` のエラー、`-h` と仕様書の一覧も)
- 右上の数、`space` の飛び先は、この新しい意味の緑で数える (語は「新着」→「未読」。反応待ちは今までどおり)
- `viewed` のファイルの形は、必要なら変えてよい (古い形のファイルが残っていても落ちず、読めなければ無いものとして扱う)
- `-h`: 属性の表と、作法に 1 つ (「読んでほしい行にだけ `look="y"` を付ける。進み具合の行のように、見なくて困らないものには付けない。答えを書いた行には付ける」)。勧める構成の例も合わせる

## 2. 印とカーソルの列を分ける

ユーザーの言葉: 「緑のアイコンとカーソルの場所が被っていてカーソル移動のたびにちらついていて嫌だな」

- カーソルの `>` と、● (黄・緑) を別の列に置く。左から: カーソルの列、印の列、行頭の記号 (`○` `✓` `?` `→` `▸`)。カーソルが乗っても印は消えず、位置も動かない
- 印の無い行も同じ幅を空けて、行頭の記号の列が全行で揃うこと
- 字下げされた行 (Fold の中など) でも、カーソルと印の列は左端に固定
- カーソルを動かしたとき、動いた 2 行以外の文字が描き変わらないこと (画面全体を消して描き直していないか確かめる。していたら、変わった行だけ書き直す)

## 3. `u` で直前の操作を取り消す

ユーザーの言葉: 「uで取り消しにしたい。例えばyをつけるとかそういうグローバルな操作全般に対して」

いまの `u` は隠した行を戻すだけ。人のした操作全般に広げる。

- `u` は、この viewer を開いてからした操作を、新しい順に 1 つずつ取り消す。対象: `y` / `n`、選択肢の答え、コメントを置く、コメントを直す (`e`)、コメントの取り消し (`x`)、行を隠す / 表示に戻す、`A`
- **まだ送っていない操作**: 無かったことにする (前の状態に戻る。`y` の前に `n` が付いていたなら `n` に戻る)
- **もう送った操作**: 取り消しを新しい未送信の入力として記録する (次に送ると AI に届く)。`changes` には `retract y hook (題)` のように出す。行の右端の状態は、取り消しが未送信の間 `取消 未送信` のように分かること (語は任せる。用語は `docs/dev/REVIEW6-result.md` の 1 の表に合わせる)
- `s` (送る) そのものは取り消せない。取り消すものが無いとき、下の行に `取り消せる操作がありません` と出す
- 取り消したら、下の行に何を取り消したかを 1 行出す (例: `y を取り消しました: hook を入れるか決める`)
- カーソルの位置は変えない。取り消した対象の行が画面の外でもよい (知らせの文で分かる)
- 記録は追記だけ (`events.jsonl` の行を消したり書き換えたりしない)。取り消しも 1 つの記録にする
- 案内の行と `?` の一覧: `u 取り消す` に。入りきらない幅で落とす順は今の `u` と同じ
- 書いている途中のエディタの中の `u` は文字 (今までどおり)

## 終わったら

- vet / test / build。pty 越しに確かめる (幅 80): 印の列とカーソルの列が分かれて j/k で印が動かないこと、`look` の印が `r` と反応で消え、カーソルの移動や開閉では消えず、書き換えで戻ること、`u` が上の対象それぞれで効くこと (送る前と後)。スクラッチパッドの空のディレクトリで。どの repo の `.pitboard/` も触らない。実物の `herdr agent prompt` / `herdr pane send-*` は実行しない
