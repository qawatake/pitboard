# FEAT13 結果

## 直した項目

- 起動時に `os.Executable()` (EvalSymlinks で解決) の更新時刻と大きさを覚える (`exe.go` の `newExeWatch`)
- tick (0.5 秒、報告の再読み込みと同じ) ごとに見直し、変わっていたら以後ずっと黄 (太字) で `新しい版があります。q で終えて、開き直してください。` を画面のいちばん上に出す (`view.go` の `draw`)
- 一時的に無い (stat 失敗) ときは何もせず、次に見えたときに覚えた値と比べる。見直しは `safely` で包み、失敗しても落ちない・何も出さない
- 知らせの行はスクロール領域の外に固定。報告のエラーの行・`未送信` の印・下の知らせ/案内はその下にそのまま。`?` の一覧と案内の文言は変えていない
- 単体テスト `feat13_test.go`: 値が違えば出る (更新時刻のみ/大きさのみ)、無いだけでは出ない、同じものが戻れば出ない、消えて別物が置かれれば出る、一度出たら消えない、画面の 1 行目に黄で出てスクロールしても残る
- pty 確認: スクラッチパッドの空ディレクトリで、コピーした実行ファイルを起動 → `rm` (出ない) → 別ビルド (`-ldflags="-s -w"`) を `cp` → 1 行目に黄で出た。`q` で終了コード 0。どの repo の `.pitboard/` も触っていない
- `docs/spec/SPEC.md` の「画面」に 2 行追記

## 推測で決めた点

- 「いちばん上」はスクロールしても残る固定の行とした (報告の先頭の行に混ぜると、スクロールで見えなくなるため)。`?` の一覧・`tab` の一覧の画面でも出す
- 狭い端末で折り返す場合は複数行になる (高さ - 2 行まで)
- 色は黄 + 太字 (目に入るように)。行頭は他の行と同じ字下げ
- 起動時に実行ファイルを stat できなければ、以後は何も見ない
- 比べるのは更新時刻と大きさだけ。inode は見ていない (`cp -p` で時刻を保ったまま同じ大きさの別物を置いた場合は気づかない)
