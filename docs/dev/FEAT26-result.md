# FEAT26 の結果

`scripts/check.sh` 通過 (vet・test・ギャラリー 218 枚・生きたページとの比較 29 件)。git には触っていない。ブラウザでの動きは playwright-cli で作業用のボードを使って確かめた: クリック、Tab のあと enter、`g` `1` で飛べた。戻るは `g -` とバーの「← 戻る」の両方で効いた
- A の書き方: `[文](#id)`。check は、その id を持つ行が無ければ行番号つきでエラーにする (`code` の中のものはリンクとして扱わない)。決めるのは `page` (`LinksOf`・`Follow`・`Span.Target` / `Num`・`Thing.Links`)。見るときに指す行が無くなっていればただの文として描く
- A のキー: `g` のあいだ、カーソルの行のリンクに 1〜9 を振る (その行のリンクだけ)。数字はリンクの直前に出し、一覧には `1 <指す行の題>` と並べる。数字を押すと、囲む Fold を開いてその行へ移る (viewer が動かしたカーソルとして扱う)。`g -` で戻る (20 まで覚える)。リンクが 1 つだけの行では `g 1 → 題` を出す。落とす順はいちばん先 (`DropRank` の `link`)
- **私の判断**: 同じ行へのリンクが 2 つあっても 1 つとして数え、自分自身へのリンクは数えない。指す行が隠してある (H で表示していない) ときは飛ばずに「隠した行です。H で表示すると行けます」と出す
- A のブラウザ: 中身の中のリンクはボタンにした (Tab で届き、enter とクリックで飛ぶ)。行の題の中のリンクは行のボタンの中にあるので span にした。クリックでは飛ぶが、Tab では届かない。飛んだあとはバーに `g - ← 戻る` を出す
- A の端末: リンクは下線つきで描く。e2e (`links_test.go`) で、飛ぶ、戻る、閉じた Fold の中の行へ飛ぶ、ほかの行には数字が付かない、を確かめた
- B: 開いた浮いた欄 (`m` の欄・コメントの欄) の高さに間を足した分だけ、ページの下に余白を足す。欄が伸びればその分も足す (`--float-h`)。`m` の欄は高さ 55vh まで、それを越えると欄の中でスクロールする。書いている途中に alt+↑↓ を押すと、入力欄から出ずにページが半画面スクロールする (`?` に書いた)
- **残したこと**: コメントの欄を開いている間は、余白は付くが後ろのページは動かせない (前からの作り)
- ギャラリー: 変種「g on a line with links」(違い `link-digits`)、「a line with one link」「after a jump」、`content-above-float` (生きたページとも比べる) を足した。`-h` (書き方の行・作法・例)・`?`・SPEC・SPEC-format・web-states も直した
