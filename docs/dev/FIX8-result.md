## 推測で決めた点

- `r` の効く条件: 画面に出ている・「報告が書き換わりました」の間でない・viewer が動かしたカーソルの 0.4 秒の間でない。開いた直後の置かれたカーソル (`placed`) でも効く (y n と違い、取り消せて害が小さいので)
- 案内で狭いときに落とす順は `y` と同じ (`x` `enter` `n` より後)。幅 80 の報告で落ちないように
- `Fold` の行の緑は中身の未読も含めて出ているので、`r` は中身ごと消す
- `y` / `n`・コメント・`x` を `u` で取り消しても、それで消えた緑の ● は戻さない (FEAT15 からそのまま)
- コメントを置いたときに読んだことにするのは、行の題が書き始めたときのままの場合だけ (書いている間に書き換わった内容は見ていないので)
