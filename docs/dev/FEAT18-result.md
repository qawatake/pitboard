# FEAT18 結果

## 直した項目

- `Item` の行頭: 開けない行は `○` `~` をやめて薄い `·` に (`markOf`)。開ける行の `▸` / `▾`、済んだ行の `✓` は今までどおり
- 右端の語: `state="doing"` で `status` が無いとき、道具が `作業中` を緑で出す (`right`)。`status` があればそれを緑で。`todo` `done` は今までどおり。人の入力の状態との並べ方も今までどおり
- `Ask` `Link` `Fold` の記号は変えていない
- `-h`: `Item` の `status` の説明、作法 (行頭は「何ができるか」、進み具合は右端の語、doing なら道具が `作業中` と出すので `status` は別のことを言うときだけ)、勧める構成の 4. を直した
- SPEC-format.md の「描き方」、SPEC.md の印の列の記号と色の意味を合わせた。`?` の一覧に記号の凡例は無かった
- テスト: `feat18_test.go` (行頭の記号、`作業中` の有無と色)。既存のテストの期待値の `○` を `·` に置き換えた

## 推測で決めた点

- `作業中` の色は、doing の `status` と同じ緑にした (`wait="you"` の doing でも `status` が無ければ緑の `作業中`)
- 隠す鍵 (`hideKey`) と反応の鍵 (`sig`) は AI が書いた `status` のままにした (道具が出す `作業中` は含めない)。行頭の記号の変更で、隠した行がまた現れることは無い
