# FEAT24: いちばん外側の折りたたみの題に、節の見出しと同じ色を付ける

ユーザーの言葉 (閉じた折りたたみが 3 つ並んだ画面の写真つき): 「セクションには色をつけたいかも。こういう折りたたみにも」

節 (`Section`) の見出しは太字の青だが、最上位に置いた `Fold` (「決まったこと」など) は地の色で、節と同じ格の区切りなのに目立たない。

- 最上位の `Fold` の題を、`Section` の見出しと同じ見た目 (太字・同じ青) にする。行頭の `▸` / `▾` も同じ色
- `Section` や `Fold` の中の `Fold` は、今までどおり地の色
- 隠した行として薄く出すとき (`H`) は、今までどおり薄く
- 仕様書に 1 行。`-h` に見た目の記述があれば合わせる
