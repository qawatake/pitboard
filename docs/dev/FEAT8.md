# pitboard: 文の表現力 (入れ子の箇条書き、小見出し、段落)

仕様: `docs/spec/SPEC-format.md`。FEAT7 が終わってから取りかかること。終わったら仕様書と `-h` も合わせる。

## なぜ

ユーザーの指摘 (スクリーンショットつき): `Item` を開いた中身が、1 つの段落に流し込まれて読めない。
書いた側は 1 行ごとに「cwd の良い点: …」「cwd の悪い点: …」「折衷: …」と行を分けていたが、viewer が続く行を 1 段落にまとめるので、
見出しのつもりの語が文の中に埋もれた。構造のある文を、構造のまま見せられるようにしたい。

部品は増やさない。**文 (段落・`Item` の中身・`Fold` や `Section` の中の文) の書き方**を、次の範囲まで広げる。

## 文の書き方

| 書き方 | 見せ方 |
|---|---|
| 空行で区切った行のまとまり | 段落。続く行は今までどおり 1 段落にまとめる。段落の間は 1 行空ける |
| `- 文` | 箇条書き。印は `·` (薄く)。折り返しは文の位置に揃える |
| 字下げした `- 文` (2 つの空白で 1 段) | 入れ子の箇条書き。3 段まで。段ごとに 2 桁字下げ。印は 2 段目 `-`、3 段目 `·` |
| `1. 文` | 番号つき。番号はそのまま出す。入れ子も可 |
| 箇条書きの下の、字下げした続きの行 | その箇条の続き (同じ箇条の文にまとめる) |
| `**語**: 文` で始まる段落・箇条 | `語` を太字にして、見出しの語として目立たせる (`:` は残す) |
| 行全体が `**…**` だけの行 | 小見出し。太字 + 節の見出しと同じ色。上に 1 行空ける (中身の先頭なら空けない) |
| 行末の空白 2 つ、または行末の `\` | そこで改行する (段落にまとめない) |
| `**強調**`、`` `code` ``、`[題](url)` | 今までどおり |

- `Item` の中身では、字下げの基準は中身の最初の行。`Section` / `Fold` の直下の文では、その部品の中の最初の文の行
- `- ` のただの行 (節の直下にあるもの) は、今までどおりカーソルが止まり `x` で隠せる。**入れ子の箇条 (2 段目以降) と、`Item` の中身の中の箇条は、止まらない** (読むだけ)
- 節の直下の箇条に入れ子があるとき、隠す単位は 1 段目の箇条と、その入れ子ぜんぶ。鍵は、その箇条と入れ子の文をつないだもの
- `check`: 4 段以上の入れ子はエラー。字下げが 2 の倍数でない箇条はエラー (行番号つき)
- `Code` の中は今までどおり生のまま

## 見え方の例

    <Item id="where">データをどこに置くか
      おすすめは折衷。

      - **cwd に置く**
        - 良い点: AI が報告をふつうのファイル編集で書ける
        - 悪い点: 起動する場所を間違えると見つからない
      - **XDG に置く**
        - 良い点: どこで起動しても見つかる
      - **折衷**: データは cwd、一覧だけ XDG
    </Item>

を開くと:

    ▾ データをどこに置くか
        おすすめは折衷。

        · cwd に置く
          - 良い点: AI が報告をふつうのファイル編集で書ける
          - 悪い点: 起動する場所を間違えると見つからない
        · XDG に置く
          - 良い点: どこで起動しても見つかる
        · 折衷: データは cwd、一覧だけ XDG

(`cwd に置く` `XDG に置く` `折衷` は太字)

## `-h`

「報告の書き方」に上の表を入れる。作法に足す: 「中身が 3 行を超えるなら、段落に流さず、箇条書きと太字の見出し語で構造を見せる。
比べるものは入れ子にする。1 つの箇条は 1 つのことだけ」

## テスト

単体テスト: 入れ子、続きの行、小見出し、番号、改行の指定、字下げの誤り、節の直下の箇条を隠す鍵。
pty 越しに、上の例を幅 80 と 44 で見る (折り返しの位置が揃うこと)。

**実物の `herdr agent prompt` と `herdr pane send-*` は実行しない**。`~/.claude/` には書かない。git は commit も push もしない。
報告は `docs/dev/FEAT8-result.md` に: 項目ごとに 1 行と、推測で決めた点だけ。画面への返事は「書きました」の 1 行。
