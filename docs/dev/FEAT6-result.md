## 項目ごと

1. 反応待ちと新着: `Item` / `Link` に `ask="y"` (`y` 以外と `done` への付与は `check` のエラー)。行頭の印の左に黄 / 緑の `●` (カーソルの `>` を優先、`Fold` は中身の印)。「見た」は `.pitboard/<session>/viewed` に追記。`space` で次の反応待ち→新着へ (閉じた `Fold` は開く)、`A` で全部を見たことに。右上に `反応待ち N  新着 N`、案内に `space 次へ`、`?` の一覧に `space` `A`
2. `-h` に "A layout to start from" (7 節と理由、作法 3 つ) を足し、`Marks:` の段落と `ask` 属性を書いた。例の `hook` に `ask="y"` を付けた

## 推測で決めた点

- `ask` は `sig` に入れない (付け足しただけでは、すでにある `y` / `n` を消さない)
- 置かれただけのカーソル (起動直後など)・「ページが変わりました」の間・`?` や `tab` の一覧の間は、0.4 秒乗っても「見た」にしない。`c` で書き始めたのも「反応した」に数える。閉じたのも「開いた」と同じに数える
- 新着の鍵に、`Link` の行き先 (`path` / `url`) も入れた (行の下に常に見えているので)
- `viewed` はハッシュ (SHA-256 の頭 16 バイト、16 進) でない行だけ読み飛ばし、読めないファイルは空とした (追記の途中で切れても全部が新着に戻らないように)
- 隠した行には印を出さず、数えず、`space` でも飛ばない (H で表示中も)
- 右上の `新着 N` は、反応待ちでない新着の数 (行の印の色と一致させた)。`Fold` 自体は数えない
- `space` は思いつきの欄からも効く (報告へ戻って飛ぶ)。`tab` の一覧では効かない。飛ぶ先が無ければ「反応待ちも新着もありません」
- `space 次へ` は狭いとき `x` と同じ順で最初に落とす
- `space` と `A` は `Option` の `key` (英小文字 1 字) にもともと使えないので、`viewerKeys` とエラー文は変えていない
- 「見た」の判定は描画のたびに見るので、0.4 秒を過ぎてから次の描画 (最長 0.5 秒の tick) で印が消える
