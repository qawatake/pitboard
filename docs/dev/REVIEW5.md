## 見ること (重要な順)

1. 送る: `s` と `ctrl+s`。送るものが無いとき、送り先が無いとき、代役が失敗する・5 秒以上かかるとき。送っても未送信の数が減らないこと、`changes` のあと右上の印が消えること。
   **打ち込む文に、人が書いた内容やシェルで解釈される文字が混ざらないか** (思いつきに `"; rm -rf ~; "` や `$(...)`、改行を書いて送る)。herdr 経由の経路はコードを読んで、引数がシェルを通らないことを確かめる
2. 問いの開閉: 閉じているとき選択肢のキーで答えが記録されないこと。開閉の状態が再読み込みで保たれること。答えたあとの右端の表示
3. IME のカーソル: エディタが開いている間、描画の出力が入力位置へのカーソル移動と `\x1b[?25h` で終わるか (半角・全角・折り返し・改行入り・幅 50)。閉じたあと・`tab`・`?`・終了時にカーソルの表示が正しく戻るか
4. 案内: `m 書く` と `? キー` が、どの行・どの幅でも出ているか。右上の印が題と重なって読めなくならないか
5. `pitboard --skill` と `pitboard -h`: 書いてあるコマンドを実際に打って、説明と動きが食い違わないか。`-h` だけを読んだ AI が報告を書き始められるか (足りない説明がないか)
6. これまでの動きが壊れていないか: 反応、思いつきの状態、行を隠す、hook (板の無いセッションで何もしない)
