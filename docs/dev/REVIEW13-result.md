## d. 鍵を serve.json に置くこと
読めるのは同じユーザーだけ (0600)。同じユーザーは、もともとブラウザの cookie も読めるし、`pitboard serve` で URL を出させることもできる。なので読める人は増えない。違いは、鍵がサーバーの続くあいだディスクに残り、何度でも cookie と交換できること。`.pitboard` を同期・バックアップ・commit すると鍵が出ていくが、使えるのは 127.0.0.1 で動いている間だけ。AI (同じユーザー) が人として操作できるようになるが、`events.jsonl` に直接書けるので、できることは増えない。弱くなるのは c-4 (0644) の場合だけ。
