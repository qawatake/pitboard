# FEAT3 の結果

vet / test / build は通った。1 は pty 越しに確かめた (スクラッチパッド、幅 80・高さ 30 と 14、送り先は `PITBOARD_SEND` の代役)。herdr は呼んでいない。

## 項目ごと

1. 思いつきの欄に j / k で入る: 報告の終わり (最後の止まる行で、画面が報告の末尾まで出ているとき) から `j` で欄の 1 件目へ、欄の 1 件目の `k` で報告の最後の止まる行へ。欄にいる間は高さの半分まで広がって全件を出し、`enter` で開閉、欄の中で送る。案内は `enter 開く  m 書く  ? キー`。`?` の一覧と仕様書に書いた
2. A: 送っている間は「送っています…」を出し、その間に押されたキーは捨てる (キーに読んだ時刻を付けて比べる)。結果は次のキーまで残る
3. B: 下の行の知らせは 1 行に収め、長ければ `…`。「送り先がありません」「隠しました (H で表示)」に短くした
4. C: エディタの案内は 1 行で、狭いと `ctrl+e` → `ctrl+j` の順に落とす。`ctrl+s 送る` に短くした
5. `-h`: `Ask` は閉じた 1 行で始まるので問いだけで意味が通るように書く、改行を含む思いつきの `changes` の例、`PITBOARD_SEND` の例 (tmux、`"$PITBOARD_MESSAGE"` を引用符で囲む) を足した

## 推測で決めた点

- 欄にいる間、報告の行の `>` は消す。報告の文は動かさない (欄が広がったぶん、下が隠れる)
- 欄の高さは「画面の高さの半分」を、見出しと上下の空行を含めた行数とした (高さ 14 なら 7 行: 思いつきは 4 行ぶん)
- 欄で開いた思いつきは、行の下に 2 桁字下げして全文・行の題・行き先 (または「まだ AI に届いていません」など) を出す。`tab` の一覧と同じ中身。開閉の状態は欄と一覧で別に持つ
- 欄に入るのは、報告の止まる行がもう無く、かつ報告の末尾が画面に出ているとき。それまでの `j` は今までどおり報告を 1 行送る
- 欄の最後の件で `j` を押しても何もしない
- 欄にいる間、案内の右の `隠した行 N` は出さない。`H` も効かない (仕様の「今までどおり」の一覧に無いので)
- herdr にこのセッションの agent がいないときは「送り先がありません (herdr にこのセッションの AI がいません)」(1 行に入らなければ `…` で切れる)
- 送っている最中に押されたキーは `ctrl+c` も含めて捨てる
- エディタの案内は、以前の 2 行に折り返す形をやめて常に 1 行にした
