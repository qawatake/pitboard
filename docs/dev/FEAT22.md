# FEAT22: `-h` の作法に 2 つ足す

`pitboard -h` (AI 向け、英語。`cmd/pitboard/usage.go`) の作法に、次の意味の文を足す。文面は任せる。この依頼はそれだけ。

- **セッションは短い形で書く**: コマンドの `-s` には、セッション id の先頭 8 文字を使う (道具が出す文と同じ形)。全部は書かない。ユーザーの言葉: 「waitコマンドにセッションのキーをフルで書いてるけどそうしないといけないんだっけ？」
- **隠された行は、報告からも消す**: `changes` に `hide` が届いたら、その行が AI にもう要らなければ report.md から消す (答えの行は必ず消す)。要る行 (進み具合など) は残してよい。ユーザーの懸念: 隠した行が報告に残り続けると、AI のコンテキストを無駄に使う
- 始め方 (Starting) の例のコマンドも、短い id の形に合わせる
