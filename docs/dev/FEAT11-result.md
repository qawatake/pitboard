vet / test / build は通った。pty 越しに確かめた (スクラッチパッド、幅 80): `hook` の行の右端が `未送信` (`\e[33m`) → `s` で `送信済` (`\e[2m`) → 別のシェルの `changes` で `既読` → `settle 1 --doing` で `対応中` → `settle 1 --done` で `対応済` (どれも `\e[2m`) と移り、`state="doing"` の `作業中` は `\e[32m`、`wait="you"` の `あなた待ち` は `\e[33m`、ほかの `順番待ち` は `\e[2m`、新着の `●` は `\e[32m`。実物の `herdr agent prompt` / `herdr pane send-*` は実行していない。

## 項目ごと

1. 言葉づかい: 画面の「思いつき」を「コメント」に、状態を 未送信 → 送信済 → 既読 → 対応中 / 保留 / 対応済 に、ほかは REVIEW6 の用語の表どおり (送る / スクロールの分け、報告が書き換わりました、表示に戻す / 元に戻す、置く、記録できませんでした など)。a7・a8 の事実と違う文を直し、AI 向けの出力を `→ now: …` / `→ now gone` にした。画面の文字列を拾い直し、古い語が残らないことをテスト (TestNoOldWords) でも見る
2. 色: `Item` に `wait="you"` (値は `you` だけ、`done` にはエラー)。`status` は `wait="you"` で黄、`state="doing"` で緑、ほかは薄く (`あなた待ち` の前方一致はやめた)。`wait="you"` は反応待ちに数えず、`space` は 反応待ち → `wait="you"` → 新着 の順
3. 行の右端: いちばん新しい入力の状態 (`y 未送信` → `y 送信済` → `y 既読`、コメントは … → `対応中` / `保留` / `対応済`)、2 件以上は件数 (`2 既読`)、`✎N` はやめた。`settle N [--doing|--hold|--done] TEXT` と、まとめる形の `settle --doing 50 "…" --done 51 "…"`。欄と一覧の状態も同じ語
4. `-h` の作法に 4 つを足し (`--doing` / `--hold`、答えを AI の判断で落とす、`wait="you"`、`wait` を作業前から)、`Thoughts:` に状態の語を書いた。仕様書・README・skill も合わせた

## 推測で決めた点

- 用語の表の `送信済み` `既読` `対応済み` は、ユーザーの決定に合わせて送り仮名なし (`送信済` `対応済`) にした。表の ctrl+s の項 (k6 の `ctrl+s 送る`、k8) は FEAT9 で ctrl+s をやめたので採らず、エディタの案内は `enter 置く  esc やめる  …`
- m13 (起こせなかったとき) は「送りました。ただ AI を起こせなかったので、チャットで一言伝えてください。」、FEAT7 の「待っていない」ときも同じ形 (「送りました。ただ AI が待っていないので…」) にした。m17 の文は FEAT7 で変えたものを使う
- `c 行にコメント` は、案内に入りきらなければ (ほかのキーを落とす前に) `c 行に書く` に縮める (1-d の注記)。幅 76 で今までどおり `x 隠す` `space 次へ` まで入る
- 開いたコメントの AI の文の頭は、状態に合わせて `対応: ` / `対応中: ` / `保留: ` とした。「書いたときの題」は「書いたときは」
- 行の右端: いちばん新しいのがコメントでも、いまの反応のキー (`y` など) は頭に残す (`y 2 既読`)。反応が「いちばん新しい」かは記録の番号で比べ、コメントは直した記録も新しさに数える
- `対応中` `保留` のコメントは欄の並びで「対応済でないもの」の側に入れる。`--doing` / `--hold` は文を省ける (`--done` は文が要る)。直したコメントは AI の状態が外れる (FEAT9 のまま)
- `settle` のまとめる形は、状態を番号の前にも後ろにも書ける。状態はその 1 組だけに効く (次の組へ持ち越さない)
- `wait="you"` は `Item` だけ (`Link` はエラー)。`wait="you"` の行に新しい印 (`●`) は足していない
- 記録の `settle` は、`done` のときは `state` を書かない (今までの記録と同じ形)
- skill には「settle で状態を付ける」を 1 行足し、「`pitboard:` で始まる行が来たら、書かれたコマンドを実行」に直した (description はそのまま)
- テストの名前の付け直しや repo の構造 (REVIEW6 の 2) は、指示に無いので手を付けていない
