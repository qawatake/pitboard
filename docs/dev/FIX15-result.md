- a. `placed` でも `x` `r` が効く (開いた直後・`enter` 後・止まる行の無い報告に `Notice` が現れた直後、いずれも pty で `hide` 記録、`u` で戻る)。`y` `n`・選択肢は `placed` の守りのまま
- b-1. 0.4 秒: `x` `y` `n`・選択肢は捨てて「いま移った行です。もう一度押すと付きます」(`x` は「…隠れます」/「…表示に戻ります」)。同じ行で同じキーをもう一度押すと効く。この間の案内に `x` `y` `n`・選択肢を出さない。`r` は 0.4 秒でも効かせ、「読んだことにしました: <題> (u で戻す)」
- b-2. `placed` + `y` `n`: 「j k で動かすと y n が効きます」(選択肢は「j k で動かすと答えられます」)
- b-3. `lock`: `y n x r c`・選択肢どれでも `報告が書き換わりました。カーソルの行を確かめてください`
- b-4. 画面の外: 「カーソルの行に戻りました」
- c. 「隠しました (H で表示、u で戻す)」(H 表示中・表示に戻すときは「(u で戻す)」)。`placed` の案内は、落とせるキーをすべて落としても入らないときだけ `j k` に縮める。`placed` の `x 隠す` は `g` `space` `enter` より後まで残す
- d. 隠した行が再読み込みで隠れなくなったら (同じ key で、隠す鍵が変わった) 「隠した行が書き換わったので、また出しました: <題>」(出ている知らせより優先、1 回)

- `internal/page` で触ったファイル: 新規 `internal/page/untouched.go` のみ (`Actions.Untouched()`: `placed` の行で効く操作)。既存ファイルは変更なし

推測したこと:
- 「次の 1 回は効かせる」は、同じ行で同じキーのときだけにした (`x` で拒まれた直後の `y` まで効くと、2 度押しの守りが崩れるため)。3 連打なら 3 回目は効く
- `x` は 0.4 秒の間も拒む側にした (この守りの目的そのもの: 2 度押しで見ていない行が消える)。`r` は行が消えず戻せるので拒まない
- 意味の無いキー (ただの行での `y` など) は知らせない (どの字も `react` に流れるので、打ち間違いがうるさくなる)

- 中身を `k` で読み戻すときも `placed` を解く
- `x` で隠して移った先の行は `placed` のまま (0.4 秒の守りに加えて)
