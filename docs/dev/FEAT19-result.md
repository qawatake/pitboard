## 推測で決めた点

- `Fold` に付いたコメントは、開いたとき題のすぐ下に、中の行の印と同じ列に `✎` で並べる (`Item` の中身のように 2 桁深くはしない。後ろに空行も入れない)。エディタはそのコメントの下 (中の行の上)
- `Fold` にコメントを置くと、`r` と同じく `Fold` とその中の未読 (隠した行・反応待ちの行を除く) の緑の `●` を消す (`Fold` の印は中身の印も兼ねるので)
- `id` の無い `Fold` の宛先は題 (`Fold|title=…`) なので、AI が題を変えると (`済んだこと (2)` → `(3)`) 前のコメントは「消えた行」扱いになり、その `Fold` の下には出ない。`changes` では `(now gone)`
- `id` のある `Fold` への `changes` は `Item` と同じ形 (`on ID (題)`) にした。`fold` とは書いていない
- 書く欄の下の空行は、画面のいちばん下を空ける決まりの空行とは別に数える
