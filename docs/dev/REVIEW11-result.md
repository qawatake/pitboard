# REVIEW11 の結果: `Notice` で `x` が効かない

確かめ方: `693db54` をスクラッチパッドに `git archive` して `go build`。スクラッチパッドの新しいディレクトリで Python `pty` + `pyte` (幅 80) で動かし、`events.jsonl` で記録されたかを見た。

| 状態 | `x` の結果 | 出る知らせ |
|---|---|---|

`r`: `placed` を見ない (効く)。0.4 秒の間と `lock` は黙って無視。`y` `n`: `placed`・0.4 秒・`lock` で黙って無視 (`placed` だけ案内あり)。`c`: `placed` でも効く (`lock` では無視)。

いちばんありそうなもの: 開いた直後に `x` (カーソルは最初の止まる行、つまり `Notice` に置かれる)。何も起きず、知らせも無く、案内は `y n` のことしか言わない。あとで `j` `k` などを押してから `x` すると効き、`s` で AI に届いた。2 番目の候補は「隠したお知らせを AI が書き換えてまた出た」(押したのに消えていない、に見える)。

案:
- a. `x` と `r` は `placed` でも効かせる。記録は `s` まで送られず `u` で戻せ、結果 (消える・● が消える) が画面で見える。`y` `n`・選択肢は AI への答えなので `placed` の守りを残す
- b. 0.4 秒・`lock`・画面の外で押したキーは黙って捨てず、知らせを出す (`いま移った行です。もう一度 x で隠す` / `カーソルの行に戻りました` / `placed` の `y`: `j k で動かすと y n が効きます`)。案内に出しているキーが効かない時間を作らない (0.4 秒の間は `x 隠す` を出さないか、知らせで補う)
- c. `隠しました` に `(u で戻す)` を付ける。`placed` の案内を `j k` だけに縮めない
- d. 隠した `Notice` が書き換わってまた出たときは、そう知らせる
