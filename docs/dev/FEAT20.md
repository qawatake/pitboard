# FEAT20: お知らせに、付けた時刻を出す

仕様は `docs/spec/SPEC.md` と `pitboard -h`。この依頼だけで完結する。

## なぜ

ユーザーの言葉: 「お知らせには何時何分くらいにつけたものかを書いてもらえると助かるかも」

人は席を外して戻ってくる。固定されたお知らせが、いま出たものか、2 時間前のものかで、読み方が変わる。

## 何を

- `Notice` に属性 `at` を足す。値は `YYYY-MM-DD HH:MM` (端末のローカル時刻)。書式が違えば `check` のエラー。任意だが、`-h` の作法で「必ず付ける。`date '+%Y-%m-%d %H:%M'` で取る。文を書き換えて知らせ直すときは時刻も新しくする」と書く
- 描き方: 題の行の右端に薄く出す。今日なら `21:46`、今日でなければ `11/23 21:46`。題はその幅を空けて折り返す (右端の語と同じ扱い。人の入力の状態があるときは、時刻の左に並べる)
- `at` の違いだけでは、隠したお知らせをまた出さない・緑や黄の印の判定に使わない (隠す鍵に入れない)
- `-h` の部品の表と例、仕様書に反映
