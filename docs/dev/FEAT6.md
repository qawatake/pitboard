# pitboard: 新着と「反応がほしい」の印、勧める構成を -h に書く

仕様: `docs/spec/SPEC.md`、`docs/spec/SPEC-format.md`。終わったら仕様書・`-h`・`?` の一覧も合わせる。

## 1. どこに反応すればよいかを見失わないようにする

ユーザーの困りごと: 報告が長くなると「どこに反応しないといけないんだっけ」と見失う。特に反応がほしい行や新着に、横に印がほしい。

### 反応がほしい行

- `Item` と `Link` に属性 `ask` を足す。値は `y` (よし / だめ を聞いている)。例: `<Item id="plan" ask="y">この方針で進めてよいか</Item>`
- 「反応待ち」の行 = まだ答えていない `Ask`、または `ask="y"` が付いていて、いまの内容に対する `y` / `n` がまだ無い `Item` / `Link`
- 反応待ちの行は、行頭の印の左 (カーソルの `>` と同じ列。カーソルがあるときは `>` を優先) に黄の `●` を出す。反応すると消える
- `check`: `ask` の値は `y` だけ。`state="done"` の `Item` に `ask` があればエラー

### 新着

- 「新着」の行 = 人がまだ見ていない内容の行。対象は `Item` `Ask` `Link` と `- ` のただの行
- 「見た」の定義: その行にカーソルが 0.4 秒以上乗った、またはその行に反応した・開いた・隠した。**画面に出ただけでは「見た」にしない**
- 鍵は行の内容 (隠すときの鍵に、開いたときの中身と `note` も加えたもの)。内容が変われば、また新着になる
- 記録先は events.jsonl ではなく、`.pitboard/<session>/viewed` (鍵のハッシュを 1 行ずつ追記。AI には届けない。壊れていたら空として扱う)
- 新着の行は、同じ列に緑の `●` を出す。反応待ちでもあるときは黄を優先
- 板を初めて開いたときは、全部が新着になる。`A` (shift+a) で「いま報告にある行をすべて見たことにする」

### 飛ぶ・数える

- `n` は「だめ」で使っているので、`space` で「次の反応待ち、無ければ次の新着」の行へ飛ぶ (下へ探し、末尾まで行ったら先頭から)。`shift+tab` … ではなく `b` で前へ
  (`space` `b` `A` は viewer のキーなので、`Option` の `key` に使えないキーへ足す。`b` はよく使われそうなので、既存の報告の `key="b"` が `check` で落ちる。
   **そのため `b` は使わず、前へ飛ぶキーは作らない**。`space` と `A` だけにする)
- 折りたたみ (`Fold`) の中に反応待ち・新着があれば、`Fold` の行にも同じ印を出す。`space` で飛ぶときは `Fold` を開いて中の行へ行く
- いちばん上の行の右端 (未送信の印の左) に、`反応待ち 2  新着 5` と出す (0 のものは出さない。反応待ちは黄、新着は緑)
- 案内: 反応待ちか新着があるとき、`space 次へ` を `m 書く` の手前に出す
- 「人が動かした」とみなすキーに `space` も入れる (飛んだ先の行ですぐ反応できる。ただし飛んだ直後 0.4 秒は効かない決まりは守る)

## 2. `-h` に、勧める構成を書く

ユーザーの要望: 報告の構成は自由だが、「まずはこんな構成にしてみては」という出発点を道具が持っていてほしい。

`-h` に "A layout to start from" の節を足す。押しつけではなく出発点だと書き、理由を 1 行ずつ添える:

1. 題と、いまの状況を 1〜2 文
2. **あなたへ**: 人の判断・確認・作業が要るもの。`Ask`、または `ask="y"` の `Item`。ここが空なら、人は何もしなくてよいと分かる
3. **答え**: 人に聞かれたことへの答え。題が問い、中身が答え。人は読んだら `x` で片付ける
4. **進行中**: AI がいまやっていること、次にやること。`status` で 作業中 / 順番待ち / あなた待ち / 保留
5. **決まったこと**: 決定を 1 行ずつ。人が不要と思えば `x` で隠す
6. **場所**: repo、ファイル、URL (`Link`)
7. **済んだこと**: `Fold` にまとめる。新しいものを上に

あわせて作法として: 上に行くほど人の手が要るものを置く。節は空なら書かない。1 画面に収まらなくなったら、済んだものを `Fold` に移すか落とす。
