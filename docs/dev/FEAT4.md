# pitboard: エディタのカーソル移動、思いつきの取り消し、板が無いときの文言

仕様: `docs/spec/SPEC.md`、`docs/spec/SPEC-format.md`。終わったら仕様書・`-h`・`?` の一覧も合わせる。

## 1. エディタでカーソルを動かせるようにする

ユーザーの要望: 思いつきを書くエディタで、Claude Code の入力欄でできる程度の編集をしたい。
いまは末尾への追記と末尾の削除しかできない。文中にカーソルを置いて編集できるようにする (readline / emacs 風)。

| キー | 動き |
|---|---|
| `←` `→` / `ctrl+b` `ctrl+f` | 1 字左 / 右 |
| `↑` `↓` / `ctrl+p` `ctrl+n` | 上 / 下の行へ (折り返した見た目の行で。桁は全角を 2 として近い所へ) |
| `ctrl+a` / `ctrl+e` / `home` / `end` | 行頭 / 行末 (改行で区切った行) |
| `alt+b` / `alt+f` / `alt+←` / `alt+→` | 語単位で左 / 右 (空白と、かな・漢字・英数の種類の変わり目で区切る) |
| `backspace` / `ctrl+h` | 左の 1 字を消す |
| `delete` / `ctrl+d` | 右の 1 字を消す (空のとき `ctrl+d` は何もしない) |
| `ctrl+w` / `alt+backspace` | 左の 1 語を消す |
| `ctrl+k` | カーソルから行末まで消す |
| `ctrl+u` | 行頭からカーソルまで消す |
| `ctrl+j` / `shift+enter` / `alt+enter` | 改行を入れる |
| `enter` | 書く |
| `ctrl+s` | 書いて送る |
| `ctrl+g` | 外のエディタ (`$VISUAL` / `$EDITOR` / `vim`) で続きを書く。**これまでの `ctrl+e` から変える** (`ctrl+e` を行末に使うため) |
| `esc` | やめる |

- 文字の入力と貼り付けは、カーソルの位置に入る
- 本物の端末のカーソルを、文中のカーソルの位置に置く (IME の変換中の文字がそこに出る。今の「末尾に置く」を一般化する)
- エディタの文が高さに収まらないときは、カーソルの行が見えるように送る
- これまで書いている間の `↑` `↓` は「上の報告を動かす」だったが、文の中の移動に変える。上の報告を送るのは `pgup` `pgdn` のまま
- 編集の処理は、画面と切り離した小さな型 (文とカーソル位置を持ち、キーごとのメソッドを持つ) にして、単体テストを書く
  (全角、絵文字、結合文字、空の文、行頭・行末・文頭・文末での各キー、折り返しをまたぐ上下)
- エディタの案内: `enter 書く  ctrl+s 送る  esc やめる  ctrl+j 改行  ctrl+g エディタ` (狭いときは後ろから落とす)

## 2. 思いつきを取り消す

ユーザーの要望: 間違えて書いた思いつきを消したい。

- 思いつきの欄 (j で入った所) と `tab` の一覧で、行の上の `x`: その思いつきを取り消す。欄・一覧・報告の行の下・`✎` の数から消える
- 記録は追記だけ: `{"n":12,"t":"...","op":"retract","thought":9}`
- 取り消した直後は、下の行に「取り消しました (u で戻す)」と出す。**次のキーが `u` なら戻す** (`{"op":"unretract","thought":9}`)。ほかのキーを押したら、それ以降は戻せない
- AI への届き方 (`changes`):
  - まだ届いていなかった思いつきを取り消したら、思いつきも取り消しも**届けない** (AI は最初から知らない)。未送信の数にも数えない
  - すでに届いた思いつきを取り消したら、`retract thought 9: <本文の頭>` と届ける。`-h` に書く: 「人がその思いつきを取り下げた。対応していたらやめる。`settle` は要らない」
  - すでに行き先 (`settle`) が付いた思いつきも取り消せる (同じ扱い)
- 取り消した思いつきへの `settle` はエラーにしない (黙って受ける)
- 案内: 欄・一覧の行の上では `enter 開く  x 取り消す  m 書く  ? キー`
- 「viewer がカーソルを動かした直後 0.4 秒は効かない」決まりを、この `x` にも当てはめる (取り消したあとカーソルが次の件に移るので、連打で次々消えないように)
- 単体テスト: 届く前 / 届いたあとの取り消しと `changes`、`u` で戻す、未送信の数

## 3. 板が見つからないときの文言

viewer を、板の無いディレクトリで起動すると理由が分からない (ユーザーが repo のディレクトリで起動して「なにもありません」と出た)。

- `-s` なしで、カレントディレクトリと親のどこにも `.pitboard/` が無いとき:
  「このディレクトリと親に板 (.pitboard/) がありません。AI のセッションを動かしているディレクトリで起動してください」と出して待つ (板ができたら描く、は今までどおり)
- `.pitboard/` はあるがセッションが 1 つも無いとき: 「板はまだありません。AI が報告を書くと、ここに出ます」
- 画面のいちばん下に、いま見ている場所を薄く出す: `<.pitboard のあるディレクトリ>` (ホームは `~` に)
