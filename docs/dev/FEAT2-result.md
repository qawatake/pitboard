# FEAT2 の結果

vet / test / build は通った。1 と 2 はスクラッチパッドの空のディレクトリで pty 越しに確かめた (幅 80 と 36)。

## 項目ごと

1. 送る: `s` / エディタの `ctrl+s` で、`PITBOARD_SEND` → herdr (`herdr agent list` の `result.agents[].agent_session.value` で照合 → `herdr agent prompt <pane_id> <文>`) の順に送る。5 秒で打ち切り、`seen` は進めない。右上の `● 未送信 N`、欄の見出しの `s で送る` も入れた (`send.go`、`view.go`)
2. `m 書く` を案内に常に出し (`? キー` の手前)、`c 行に書く` にした。狭いときは x → enter → n → y → c の順に落とし、`m` と `?` は最後まで残す
3. `skills/pitboard/SKILL.md` (薄い skill) を作り、`skill.md` を消した。`--skill` はこれを埋め込む。中身は `pitboard -h` に移した。**形は `-h` 1 つに全文** (183 行。`pitboard docs` には分けなかった)。README に入れ方を書いた
4. エディタが開いている間は、本物のカーソルを入力位置に置いて見せる (描画と同じ 1 回の書き込みで)。反転の四角はやめた。閉じたら隠す
5. `Ask` は閉じた状態で始まる。選択肢のキーは開いているときだけ効き、閉じているときは開くだけ。閉じていて答えがあれば、右端に `a 全部やる…` (入らなければ `a`)

## 推測で決めた点

- pty での確かめは、送り先を `PITBOARD_SEND` にした。herdr の代役 (`herdr` という名前の実行ファイル) を置く操作が、手元の権限確認で拒まれたため。herdr 経由の送信は、単体テストで代役のスクリプトを PATH の先頭に置いて確かめた (`feat2_test.go`)
- `s` は `tab` の一覧でも効く。一覧の案内にも `m 書く` を出す (「常に出す」を一覧にも当てはめた)
- エディタの案内は `enter 書く  ctrl+s 書いて送る  ctrl+j 改行  ctrl+e エディタ  esc やめる` にした (enter が「送る」のままだと紛らわしいため)
- 空のエディタで `ctrl+s` を押すと、エディタを閉じて送るだけ (未送信があれば送る)
- herdr にこのセッションの agent が見つからないときは「送り先がありません (herdr にセッション ID の AI が見つかりません)」
- 送っている間 (最大 5 秒) は viewer が止まる (別の goroutine にはしなかった)
- 閉じた `Ask` に出す選択肢の文の頭は 12 桁まで。「入らない」は、問いの文と右端がその行に収まらないとき
- 閉じた `Ask` に、人が一度も動かしていないカーソルがあるとき、案内は `j k 動かすと x が効く` (開いているときは今までどおり `動かすと答えられる`)
- `● 未送信 N` は `settle` 以外の、`seen` より後の操作を数える (`unhide` も数える)。`?` のキー一覧の画面には出さない
- 思いつきの欄の `s で送る` は黄 (以前の `未読 N` と同じ色)
- skill の description に「チャットに `pitboard:` で始まる行が来たとき」も使う、と足した
