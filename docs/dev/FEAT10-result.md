# FEAT10 の結果

vet / test / build は通った。2 は pty 越しに、空白を含むパスの画像ファイルを bracketed paste で貼る経路で確かめた (スクラッチパッド、幅 80): エディタに `[Image #1]` が入り、`images/1.png` (0600、`images/` は 0700) ができ、`changes` に `  image 1: <絶対パス>` が付いた。クリップボードには触っていない (取り出しは代役で単体テスト)。実物の `herdr agent prompt` / `herdr pane send-*` は実行していない。

## 項目ごと

1. 起こす文を `pitboard: N sent. Run: pitboard -s SESS changes` に (SESS は板のディレクトリで一意な最短の先頭、最低 8 字)。`changes` は hide / unhide を最後に 1 行ずつ (題 20 字)、押し直した反応は最後だけ、思いつきの紐づけ先の題は 30 字。`settle` は `N TEXT` の組を並べられる (1 組の形もそのまま)。`-h` に意味と「wait がいちばん安い」を書いた
2. 画像: エディタの `ctrl+v` でクリップボードの画像を `images/<N>.png` に保存して `[Image #N]` を入れる (macOS は osascript + sips、Linux は wl-paste / xclip、3 秒、20 MiB まで)。画像ファイルのパス 1 つの貼り付けも同じ。`[Image #N]` は薄く描き、`changes` / `wait` / hook で文に残っている画像のパスを添える。`?` の一覧に `ctrl+v`

## 推測で決めた点

- 押し直した反応を 1 つにまとめるのは、同じ `send` で届く分の中だけ
- hide / unhide の行は、ほかの行のあと (いちばん最後) に置いた
- 30 字で切るのは、思いつきの行の括弧の中の題 (書いたときの題と、`→ いまは:` の題のそれぞれ)。反応の行の題は切っていない
- `settle` の複数の形は「引数が 4 つ以上の偶数個で、1 つおきに全部が番号」のとき。それ以外は今までの 1 組 (N のあとの語をつなぐ)。番号のどれかが無い・文が空なら 1 つも書かない
- hook の最後の行も `settle N TEXT [N TEXT ...]` にした
- 画像の番号は `images/last` と既存ファイルの大きいほうの次 (消しても再利用しない)。貼り付けたファイルは拡張子を保つ (`.jpeg` は `.jpg`、変換しない)
- パスの貼り付けとして読むのは、絶対パス (と `~/`、`file://`) で、`'…'` `"…"` の囲みや `\ ` のエスケープも外す。相対パスは文のまま
- 大きすぎるパスの貼り付けは、文 (パス) をそのまま残して知らせを出す
- エディタの案内には `ctrl+v` を出していない (`?` の一覧だけ)
- `changes` に添える画像のパスは、ファイルが今あるものだけ (消した画像は添えない)
